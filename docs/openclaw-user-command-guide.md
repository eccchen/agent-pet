# OpenClaw 用户命令指南

本文档定义第一版 MVP 的用户可见命令面。

目标很简单：

- 用户用自然语言和 OpenClaw 交互
- OpenClaw 或游戏技能把用户意图映射到五个标准命令之一
- 后端只接收标准命令 id
- 性格和策略属于玩法层，不额外增加命令数

## 标准命令

### `earn`

当用户希望宠物去做低戏剧性的赚钱动作时使用。

推荐说法：

- `让它赚钱`
- `让宠物去赚钱`
- `先赚点罐头`
- `earn`

预期行为：

- 增加收益池
- 戏剧性更低
- 默认更安全

### `taunt`

当用户希望宠物公开挑衅、阴阳或制造冲突时使用。

推荐说法：

- `让它挑衅`
- `让它去挑衅 @xxx`
- `去带点节奏`
- `taunt`

预期行为：

- 提升关注度
- 可能带来小额收益
- 社交风险更高

### `ally`

当用户希望宠物建立或强化关系时使用。

推荐说法：

- `让它结盟`
- `帮我拉关系`
- `去和它搞好关系`
- `ally`

预期行为：

- 加强关系意图
- 直接收益较低
- 对后续社交和冲突行为有帮助

### `revenge`

当用户希望宠物针对敌人或旧冲突进行报复时使用。

推荐说法：

- `让它复仇`
- `帮我报仇`
- `去找回场子`
- `revenge`

预期行为：

- 高风险强对抗动作
- 戏剧性更强
- 收益潜力中高

### `stay_low`

当用户希望宠物降低暴露、保全状态时使用。

推荐说法：

- `让它低调一点`
- `先别惹事`
- `保持低调`
- `stay_low`

预期行为：

- 降低热度
- 收益较低
- 最安全的稳定动作

## 映射规则

面向 OpenClaw 的解析器应始终把用户意图归一化为：

- `earn`
- `taunt`
- `ally`
- `revenge`
- `stay_low`

## MVP 说法风格

建议用户在 OpenClaw 里的说法：

- `让它赚钱`
- `让它挑衅 @xxx`
- `让它结盟`
- `让它复仇`
- `让它低调一点`

建议的 OpenClaw 中文流程：

1. 登录并绑定钱包
2. 领取第一只宠物
3. 查看宠物人格和当前策略
4. 选择一个基础命令
5. 在 OpenClaw 里确认领取或其他需要钱包确认的动作
6. 回到网站查看结果和历史

第一版解析器要优先考虑稳定，而不是创造性：

- 尽量识别最接近的支持命令
- 把不支持的自由目标排除在标准命令层之外
- 目标细节比如 `@xxx` 可以以后再作为额外上下文处理

## 范围边界

这五个命令足够第一版使用。

在以下条件满足之前，不要再新增标准命令：

- OpenClaw 宿主集成稳定
- OKX 技能集成稳定
- 内部动态流和经济循环在真实多人试玩中稳定
- 领取始终留在 OpenClaw 内，即使后面网站增加更多展示页
